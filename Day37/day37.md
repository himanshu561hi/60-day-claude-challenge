# Day 37: Task Compass

## Objective
Build a single-file, offline-capable HTML application that serves as an interactive management simulation. The goal is to teach players about ownership, delegation, collaboration, and how work flows through real tech companies, moving away from a standard quiz format towards a strategy-like game feel.

## Technical Implementation
- **Tech Stack**: Vanilla HTML, CSS, JavaScript.
- **Design System**: Premium modern UI featuring dark mode, glassmorphism, animated gradients, and distinct role colors.
- **Interactions**: Utilizes native HTML5 Drag and Drop API, augmented with click-to-select for mobile accessibility.
- **Audio**: Procedurally generated subtle sound effects using the Web Audio API.
- **Data Management**: Scenarios are stored as JavaScript objects, randomly shuffled to provide replayability across 3 stages.
- **Data Visualization**: A custom CSS-based animated bar chart for final scoring.

## Features
1. **Stage 1: Ownership**: Identify the primary owner for specific technical tasks.
2. **Stage 2: Task Routing**: Build the correct organizational workflow for incoming issues.
3. **Stage 3: Collaboration**: Assemble cross-functional task forces for major events.
4. **Final Reflection**: Instead of raw scores, provides insightful, nuanced feedback based on the player's choices.
