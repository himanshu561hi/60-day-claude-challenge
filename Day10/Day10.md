# Day 10: Build Your Personal Portfolio Website

## 📌 Project Overview

Today's challenge focused on personal branding and web development by building a modern, single-file portfolio website. This digital profile serves as a comprehensive hub showcasing my engineering background, technical expertise, and development milestones.

## 🛠️ Tech Stack Used

* **Frontend:** HTML5, Semantic Markups
* **Styling:** Tailwind CSS (via CDN) for modern, responsive, and utility-first design
* **Interactivity:** Vanilla JavaScript for dynamic light/dark mode toggling and smooth scrolling

## 🚀 Core Features Implemented

* **Hero Section:** Clean introduction featuring a typing animation effect and direct professional links.
* **About Me:** Summarized focus on full-stack development, AI agent creation, and building impactful products.
* **Skills Dashboard:** Structured categories highlighting core technologies (MERN Stack, Next.js, Tailwind), AI engineering tools (Gemini/OpenAI APIs, Supabase), and professional soft skills.
* **Featured Projects:** Grid showcase for high-impact builds including an AI Interviewer platform, Secure Online Exam Proctoring system, and automated internship management workflows.
* **Achievements & Experience:** Bulleted chronicle of hackathon participations (Smart India Hackathon, Tech Fusion) and entrepreneurial initiatives like founding Code-A-Nova.
* **Theme Control:** Fluid Dark/Light mode toggle to adapt to recruiter viewing preferences.
* **Fully Responsive:** Completely optimized for seamless viewing across mobile, tablet, and desktop viewports.

## 💡 Key Learnings

1. **Rapid Component Styling:** Leveraging Tailwind CSS via CDN allowed for rapid UI prototyping without the overhead of build configurations.
2. **Personal Branding Architecture:** Understanding how to structure technical skill sets, active projects, and achievements to optimize for recruiter scannability.
3. **No-Build Interactivity:** Implementing dark mode and active navigation highlighting effectively using native browser APIs and vanilla JS.
