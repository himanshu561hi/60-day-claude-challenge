# Day 32: Think Like a Marketing Strategist

## Overview
"Think Like a Marketing Strategist: Grow This Brand" is an interactive web application designed to teach the fundamentals of marketing strategy. Built as a single HTML file using React (via CDN) and Babel, it allows users to formulate strategies for their own business, build a personal brand, or manage a randomly generated client. 

## Features
- **Three Play Modes**: Users can choose to use their own existing business, focus on building their personal brand, or tackle a randomly generated client with unique challenges.
- **Strategic Foundation**: Guides users to clarify their niche, target audience, competitors (or admired figures), and core challenges before writing any content.
- **Platform Strategy & Content Pillars**: Limits users to choosing 2-3 platforms and 3 core content pillars to encourage strategic focus over scattered effort.
- **Prompt Engineering Built-In**: Features "How to ask Claude" cards at every major step. These cards provide dynamic, reusable prompts using the user's specific input to demonstrate how AI can assist in the strategizing process.
- **Unexpected Events Module**: Injects random, realistic marketing or PR scenarios that force the user to make critical decisions, providing immediate feedback on their choices.
- **Growth Report**: Concludes with a comprehensive executive summary of the strategy built and three tailored "Strategist Lessons."

## Technology Stack
- **HTML5** for structure
- **CSS3 (Vanilla)** for a sleek, dark modern UI without external frameworks like Tailwind
- **React (via CDN)** for state management and reusable components
- **Babel (Standalone via CDN)** for in-browser JSX compilation

## How to Run
Simply open `index.html` in any modern web browser. The application runs locally using CDNs for the React libraries, with no npm dependencies, backend, or APIs required.
