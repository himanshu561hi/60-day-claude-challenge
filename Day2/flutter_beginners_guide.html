What is Flutter?

Flutter is Google's open-source UI toolkit for building natively compiled apps from a single codebase. It uses Dart — a fast, object-oriented language designed to feel familiar if you already know Java, JavaScript, or C#.

Flutter

The UI framework — handles widgets, rendering, animations, and platform APIs.

Dart

The programming language — compiled to native ARM code or JavaScript for the web.

Skia / Impeller

Flutter's own rendering engine — draws every pixel itself, no native UI components needed.

Key features

Hot reload

See UI changes instantly — sub-second, without losing app state. Speeds up iteration dramatically.

Widget-based UI

Everything is a widget — buttons, padding, alignment, layouts. Compose complex UIs from small pieces.

Cross-platform

One codebase → iOS, Android, Web, Windows, macOS, and Linux. True write-once, run-anywhere.

Native performance

Compiled to native code — 60/120fps animations with no JavaScript bridge overhead.

Getting started

1

Install Flutter SDK

Download from flutter.dev/get-started and add it to your PATH. Run flutter doctor to check your environment is ready.

2

Choose an IDE

VS Code (with Flutter extension) or Android Studio — both have excellent Flutter support, debugging, and hot reload built in.

3

Create your first project

Run flutter create hello_world, then cd hello_world and flutter run to launch the default counter app on an emulator or device.

No physical device? No problem — use the Android emulator from Android Studio, or the iOS simulator on macOS. You can even run Flutter apps in a Chrome browser tab.

Code samples

A stateless widget renders UI from its inputs alone — no internal state. Perfect for display-only components.

import 'package:flutter/material.dart'; void main() { runApp(const MyApp()); } class MyApp extends StatelessWidget { const MyApp({super.key}); // build() describes what UI to display @override Widget build(BuildContext context) { return MaterialApp( home: Scaffold( appBar: AppBar(title: const Text('Hello Flutter!')), body: const Center( child: Text( 'Hello, World!', style: TextStyle(fontSize: 24), ), ), ), ); } }

A stateful widget holds mutable state. Calling setState() tells Flutter to rebuild the widget with the new values.

class CounterPage extends StatefulWidget { const CounterPage({super.key}); @override State<CounterPage> createState() => _CounterPageState(); } class _CounterPageState extends State<CounterPage> { int _count = 0; // mutable state lives here void _increment() { setState(() { _count++; }); // triggers a rebuild } @override Widget build(BuildContext context) { return Scaffold( appBar: AppBar(title: const Text('Counter')), body: Center( child: Text('Count: $_count', style: const TextStyle(fontSize: 32)), ), floatingActionButton: FloatingActionButton( onPressed: _increment, child: const Icon(Icons.add), ), ); } }

Common use cases & when to choose Flutter

Startups & MVPs

Ship to iOS + Android at once with a single team — saves time and money early on.

Custom UI / Design-heavy apps

Flutter owns its renderer — pixel-perfect custom designs without platform constraints.

Consumer apps

E-commerce, finance, social, productivity — Flutter handles them all in production at scale.

Desktop + mobile

Need a companion desktop app alongside mobile? Flutter targets all 6 platforms from one repo.

When NOT to use Flutter

Pure web apps that need SEO, apps requiring deep platform-native integrations, or tiny scripts.
