# Day 33: Media Integrity Analyzer

A single-file interactive web application designed to teach media literacy through active discovery.

## Features
- **Pure Vanilla HTML/CSS/JS**: Runs entirely offline in a single file without external dependencies.
- **Ocean Blue Theme**: A sleek, dark editorial-style UI with smooth animations.
- **Interactive Challenges**: Includes "Headline Detective" and "Emotion Detector" scenarios to practice identifying clickbait and emotional manipulation.
- **Live Metrics**: Dynamically updates scores for Headline Accuracy, Source Reliability, Emotional Manipulation, and Audience Targeting.
- **Actionable Takeaways**: Explains core concepts, rewrites misleading content neutrally, and provides practical habits for everyday media consumption.
