# Day 19: Build a Football Intelligence Hub

## 📌 Project Overview

Built an interactive **Football Intelligence Hub** using Claude (Low effort level) and a structured football data workbook. The system acts as a Football Intelligence Analyst, Sports Educator, and Personality Assessor to drive a 4-stage personalized experience.

## ⚙️ Workflow & Stages Implemented

1. **Stage 0: Knowledge Level Check** — Gauges user familiarity to dynamically adjust explanation depth and terminology.
2. **Stage 1: FIFA World Cup 2026 Prediction Report** — Analyzes contender strength, player info, and historical trends to predict winners, runners-up, and dark horses with explicit confidence scores and risk metrics.
3. **Stage 2: Football IQ Quiz** — An adaptive 4-5 question multiple-choice quiz that evaluates and scores user football awareness.
4. **Stage 3: Messi vs Ronaldo Personality Match** — A 10-15 question behavioral and decision-making assessment to map the user to a specific football personality archetype and provide tailored recommendations.

## 🧠 Key Learnings

* **Context-Driven Prompting:** Learned how to feed multi-stage instructions to an LLM to maintain a stateful conversation across data analysis, testing, and profiling.
* **Dynamic Content Tuning:** Observed how AI adjusts its tone, complexity, and sports jargon based on an initial user profile check.
* **Structured Evaluations:** Analyzed data to generate weighted confidence scores alongside counter-arguments/risks rather than blind predictions.
