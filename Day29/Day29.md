# Operation Lifeline: Supply Chain Crisis Lab 🌐⚡

An enterprise-grade business simulation web application built for the **ABTalks 60 Days Coding Challenge (Day 29)**. This interactive application places users in the hot seat of a Chief Supply Chain Officer (CSCO) navigating severe global disruptions.

## 🚀 Live Demo & Repository

- **Challenge Day:** Day 29
- **Tech Stack:** HTML5, CSS3 (Custom Premium Dark Theme), React (via CDN), Babel JSX

---

## 🎯 Project Overview

`Operation Lifeline` is designed to teach complex supply chain management concepts to complete beginners. Through interactive storytelling, data-driven dashboards, and branching scenarios, players experience the high-stakes world of enterprise risk management.

### Key Features Included

1. **Dynamic Company Generator:** Generates unique enterprise profiles with varying metrics (revenue, factory locations, lead times, and inventory days).
2. **Random Crisis Engine:** Simulates real-world disruptions like factory fires, port strikes, cyberattacks, and geopolitical conflicts.
3. **The War Room:** A tactical decision-making hub where players execute strategic response actions that dynamically update KPIs (Cost, Inventory, Profit, Delivery Speed, Customer Satisfaction).
4. **Interactive Negotiation Stage:** A 4-round branching supplier negotiation engine that tracks Price, Trust, and Lead Time in real-time.
5. **CEO Boardroom:** 5 high-level multiple-choice leadership questions to evaluate executive decision-making.
6. **AI Strategy Integration:** Allows players to allocate budgets toward cutting-edge AI investments (Demand Forecasting, Procurement Copilots, etc.).
7. **Comprehensive Analytics Dashboard:** Scores performance across 6 custom vectors (Resilience, Negotiation, Leadership, etc.) and provides personalized dynamic feedback (Best Decision, Biggest Mistake, and Lessons Learned).

## 🛠️ Architecture & Requirements

To meet strict technical constraints, this entire application runs **offline as a single file**:

- **Zero Framework Overhead:** No `npm`, `Webpack`, or external build steps.
- **Pure Core Stack:** Powered strictly by React via CDN + Babel compiler.
- **No External Assets:** Tailwind CSS, external images, and external icon libraries were omitted in favor of native CSS animations, custom layouts, and highly optimized UI components.

### How to Run Locally

1. Clone the repository: `git clone <your-repo-url>`
2. Navigate to the project folder.
3. Double-click `index.html` to launch the simulation instantly in any modern web browser.
