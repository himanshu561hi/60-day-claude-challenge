30-day full stack web development roadmap for intermediate B.Tech student

Duration

30 days

Daily time

2+ hrs

Projects

4 builds

Goal

Full Stack

Week 1 — Frontend
Week 2 — Backend
Week 3 — Database + API
Week 4 — Full Stack Build
🏁 Outcome
Week 1

HTML, CSS & JavaScript Foundations

Milestone: Build a responsive personal portfolio page with HTML/CSS and add interactivity with vanilla JS

Daily tasks

D1HTML structure, semantic tags, forms — build a profile page skeleton
D2CSS Flexbox + Grid — style your profile page responsively
D3CSS animations, transitions, media queries — mobile-first tweaks
D4JS fundamentals — DOM manipulation, event listeners, console exercises
D5JS arrays, objects, fetch API — dynamic content with mock data
D6Project work — wire up JS to your portfolio, add a "projects" section
D7Review + deploy portfolio on GitHub Pages

Resources

The Odin Project — HTML/CSS path (free, project-based)
MDN Web Docs — HTML & CSS reference
JavaScript.info — modern JS tutorial (read chapters 1–8)
Flexbox Froggy + Grid Garden — interactive CSS games (30 min)
YouTube: Traversy Media — Flexbox crash course (video)

Week 1 project

Responsive Portfolio Site

Personal site with About, Projects, and Contact sections. Deployed live on GitHub Pages.

HTML CSS Grid JS DOM
Week 2

React + Node.js / Express

Milestone: Build a React frontend that fetches data from your own Express server

Daily tasks

D8React intro — components, JSX, props. Convert your portfolio to React
D9React state, useState, useEffect — build a todo list
D10React Router — multi-page SPA navigation
D11Node.js basics — modules, file system, npm. Set up Express project
D12Express routes, middleware, REST concepts — build CRUD endpoints
D13Connect React to Express — fetch data, handle loading/error states
D14Polish + document your React+Express mini-app

Resources

React official docs — react.dev (new beta docs, best intro)
Scrimba — React course (interactive, free tier)
Express.js official docs — expressjs.com
YouTube: Fireship — "React in 100 seconds" + Express crash course
Postman (tool) — test your API endpoints

Week 2 project

Notes App (React + Express)

Create, read, update, delete notes. React frontend communicates with a local Express REST API.

React Express REST API
Week 3

MongoDB + Authentication + Deployment

Milestone: Add a real database and JWT login to your app, then deploy to the internet

Daily tasks

D15MongoDB + Mongoose — schemas, models, connect to Atlas (free cloud DB)
D16CRUD with MongoDB — replace in-memory store in your Express app
D17Authentication — bcrypt password hashing, user schema
D18JWT auth — generate tokens, protected routes middleware
D19React auth flow — login/signup forms, store token, protected pages
D20Deployment — Render (backend) + Vercel (frontend), environment variables
D21End-to-end test, fix bugs, write a README

Resources

MongoDB University — M001 free course (official, beginner-friendly)
Mongoose docs — mongoosejs.com
YouTube: Web Dev Simplified — JWT Auth from scratch
Render.com & Vercel.com — both free-tier deployments
dotenv npm package — managing environment secrets

Week 3 project

Auth-enabled Notes App (deployed)

MongoDB-backed notes with user registration, login, and live URL. Share the link on LinkedIn!

MongoDB JWT Auth Deployed
Week 4

Capstone — Full Stack App

Milestone: Ship a complete, deployed, portfolio-ready full stack project from scratch

Daily tasks

D22Plan your capstone — wireframes, data models, feature list (keep it scoped!)
D23Set up monorepo (client + server), initialize DB schema, configure env
D24Backend — build all API routes, test with Postman
D25Frontend — layout, routing, connect to API, handle auth
D26Polish UI — responsive design, loading states, error messages
D27Deploy full stack — test on production URL, fix any cross-origin issues
D28–30Write README + case study, add to portfolio, share on GitHub + LinkedIn

Capstone ideas (pick one)

Job Tracker

Track job applications with status columns (applied, interview, offer). Auth + CRUD + filters.

Dev Blog Platform

Markdown blog with user accounts, post creation, and public reading view.

Expense Splitter

Split bills between friends with group management and balance calculations.
