## 🏆 Capstone Project: AI Recruiter Platform

The final 10 days (Days 51–60) culminated in building and shipping **AI Recruiter** (`ai-recruiter`), an autonomous voice interviewing and candidate evaluation platform live at **[interviewerr.vercel.app](https://interviewerr.vercel.app/)**.

### Capstone Highlights:
- **Real-Time Voice AI:** Sub-500ms voice turn-taking integrated with Vapi.ai SDK.
- **LLM Evaluation Engine:** Google Gemini 1.5/2.0 generating structured JSON candidate scorecards.
- **Full-Stack Architecture:** Next.js 15 App Router, Tailwind CSS v4 glassmorphism UI, Supabase PostgreSQL with RLS.
- **Recruiter Analytics:** Dynamic dashboards displaying candidate submission lists, ratings, and full audio dialogue transcripts.
