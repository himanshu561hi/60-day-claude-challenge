How this was built

CodeMentor AI is a purpose-built assistant tailored for junior developers. Instead of a generic chatbot, it forces Claude to structure outputs into a highly educational and actionable report.

System Prompt Design

The "Brain" of this assistant relies on a system prompt that mandates a strict Markdown format containing four sections:

  • 🐛 Bugs & Issues: Objective code analysis.
  • 💡 Best Practices: Friendly mentorship advice.
  • 🛠️ Refactored Code: Functional generated code.
  • 📚 Mentor's Note: Encouraging closure.

It explicitly handles edge cases by redirecting off-topic conversations gracefully.

UI Choices

The interface is designed to emulate a premium, modern developer tool:

  • Deep dark theme (#0b0f19) with glassmorphism panels to reduce eye strain.
  • Custom inline Markdown parser to render beautiful report cards, bypassing external libraries.
  • Fira Code monospace font specifically used for all code rendering to maintain standard dev environments.

Extensibility

Developers could expand this codebase by:

  • Adding tools (e.g. a Sandbox execution environment).
  • Persisting the session memory (messages array) into localStorage.
  • Adding multi-turn flows (e.g. "Review Mode" vs "Quiz Mode").
