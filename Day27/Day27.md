# Day 27 — Prior Authorization Story Simulator

## 📌 Project Overview

For Day 27 of my **60 Days Coding Challenge**, I built an interactive **Prior Authorization Story Simulator** that transforms a complex healthcare administrative workflow into an engaging storytelling experience.

Rather than presenting static information, this simulator guides users through a realistic patient journey where they learn how the Prior Authorization (PA) process works—from diagnosis to insurance approval—through interactive conversations and decision-based scenarios.

The project demonstrates how software can simplify difficult healthcare concepts using modern frontend development techniques and user-centered design.

---

# 🎯 Problem Statement

Prior Authorization is one of the most misunderstood administrative processes in healthcare.

According to the **AMA 2023 Survey**:

- Prior Authorization contributes to treatment delays in the majority of cases.
- Denials often require physician offices to spend more than **2 hours** resolving documentation issues.
- Patients frequently don't understand why treatments are delayed.

This project aims to educate users by simulating the complete workflow in an intuitive and interactive way.

# 💻 Development Approach

One of the biggest challenges I gave myself was avoiding frameworks.

The entire application is built using **pure JavaScript** while dynamically creating every UI component using:

- `createElement()`
- `appendChild()`

No frontend frameworks.
No virtual DOM.
No component libraries.

This helped strengthen my understanding of DOM manipulation and application architecture.
