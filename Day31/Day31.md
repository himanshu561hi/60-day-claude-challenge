# Day 31: AI Supply Chain Control Tower

## Overview
This project simulates the experience of being the Head of Operations in a global supply chain company. The application is built as a complete, interactive Control Tower contained within a single HTML file using HTML, CSS, and Vanilla JavaScript. 

## Features
- **Real-Time KPIs**: Live updates for Service Level, Customer Satisfaction (CSAT), Inventory Health, Transportation Efficiency, Operating Cost, Revenue Protected, and Overall Score.
- **Dynamic Alerts**: Randomly generated operational disruptions such as Port Congestions, Supplier Delays, and Weather Disruptions.
- **Decision Engine**: Each alert provides different strategic decisions, which directly impact the live KPIs and future risks. 
- **Time Pressure**: The simulation lasts for 3 minutes. As time progresses, the frequency of alerts increases.
- **Interactive UI**: Animated KPI cards, a live scrolling event log, a countdown timer, and priority color coding (critical vs. medium).
- **Post-Shift Analytics**: After the shift ends, a performance summary is presented along with a final grade (A+ to F).

## Technology Stack
- **HTML5** for structure
- **CSS3 (Vanilla)** for a premium dark operations center design
- **JavaScript (Vanilla)** for all game logic, timers, and DOM manipulation

## How to Run
Simply open `index.html` in any modern web browser. It runs completely offline without any external dependencies (other than a standard Google font).
