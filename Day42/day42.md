# Day 42: Personal Financial Command Center

This project is a premium single-page HTML application designed as a Personal Financial Command Center specifically tailored for **Freelancers** focusing on **managing variable income and cash flow**.

## Features

- **Self-contained HTML:** Built exclusively using Vanilla HTML, CSS, and JavaScript. No external libraries or frameworks.
- **Premium UI/UX:** Responsive design, sleek dark mode aesthetics, and smooth animations mimicking a commercial financial platform.
- **Freelancer-centric Modules:**
  - **Financial Health Score:** Calculated based on cash flow stability, tax savings, and emergency funds.
  - **Cash Flow Tracking:** Visualizing variable income streams vs. business and personal expenses.
  - **Tax & Savings:** Automatic estimated tax projections to ensure preparedness.
  - **What-If Simulations:** Projecting financial changes if income drops or rates increase.
  - **AI Recommendations & Tips:** Tailored financial advice and prompts for freelancers.
- **Local Storage Integration:** Persists user data securely in the browser.
- **Printable Reports:** Generate clean, print-friendly views of the dashboard.

## Technical Details

- **Custom Charts:** Implemented using CSS flexbox/grid and vanilla JavaScript DOM manipulation without external charting libraries.
- **State Management:** A lightweight vanilla JS system handling local storage sync and UI reactivity.
- **CSS Variables:** Extensive use of CSS custom properties for easy theming and responsive design.
