# Day 34: Marketing Detective

Marketing Detective is a single-file HTML application built as a detective game where the user analyzes marketing campaigns, finds mistakes, and cracks the case.

## Features
- **Interactive UI**: A premium dark detective aesthetic using corkboards, folders, sticky notes, push pins, paper textures, glowing accents, and smooth transitions.
- **Randomized Cases**: 15 detailed fictional marketing cases, randomly loaded per session.
- **Draggable Evidence**: Interact with the evidence cards by dragging and dropping them around the board.
- **Metrics Dashboard**: Animated charts and budget allocation bars for analyzing campaign performance.
- **Investigation Flow**: Case Assignment -> Investigation Board -> Interactive Investigation -> Solve the Case -> Case Closed -> Learning Report.

## Technologies Used
- HTML5
- CSS3 (Vanilla CSS, Custom Properties, Animations)
- Vanilla JavaScript (DOM manipulation, Drag and Drop API)

## How to Run
1. Open `index.html` in any modern web browser.
2. No external dependencies, build steps, or servers required.

## Color Theme
🔵 **Midnight Blue** — Deep navy & electric cyan with steel accents.
