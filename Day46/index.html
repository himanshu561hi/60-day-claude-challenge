Agent Responsibilities

  • Planner: Drafts the blueprint.
  • Executor: Writes the initial code.
  • Evaluator: Scores out of 100.
  • Critic: Provides actionable feedback.
  • Improver: Refines code iteratively.

Stop Conditions

Loop ends if: (1) Score hits 100, (2) Improvement plateaus for 2 rounds, or (3) Max 5 rounds cap is reached.
